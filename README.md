# steam-bbcode README

This widget, only the highlighting effects in .steam files. Support h1,h2,h3,b etc...

[github](https://github.com/gobbi-source/steam-bbcode)

## Features

![feature highlighting](https://i.imgur.com/FEgM4xZ.png)

This widget highlights and color-codes the content of various Steam BBCode parameters, and can also auto-complete them when possible. The file must have a .steam or .bbcode extension to be automatically recognized.
Additionally, as you can see from the images, the H1, H2, and H3 headings are larger and use the same color scheme as on Steam.
